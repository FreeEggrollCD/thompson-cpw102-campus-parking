# Product Requirements

**Project:** Campus Parking Helper

**Team members:** Jonathon Thompson

**Date:** 30 Sep 2026

## User and problem

Who is the user? Campus staff

What problem does the user have? They need to calculate cost of parking per hour

## Goal

Our program will help the user: The program will calculate the cost of parking per hour, including partial hours

## Requirements

Write three things the program must do. Make each one specific enough to test.

1. The program must handle partial hours.
2. The program must scalable.
3. The program must be easily used from the terminal/command line.

## Not included

What will this version **not** do?

- GUI

## Success

We will know the product works when: We'll know the program works when it returns the accurate price of parking.
